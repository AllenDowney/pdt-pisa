# pdt-pisa

Metadata for the [Programme for International Student Assessment (PISA), student questionnaire](https://webfs.oecd.org/pisa2022/index.html), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

The OECD's assessment of 15-year-old students in reading, mathematics and science, with a student questionnaire, every three years since 2000 in up to 81 countries and economies.

## Terms of use

The terms are at https://www.oecd.org/en/about/terms-conditions.html. The OECD lets its data be copied, adapted and redistributed for any purpose, with credit; written content since July 2024 is CC BY 4.0. Allen Downey reviewed the terms on 2026-11-19: the data, documentation and metadata may ship, and the documentation may be processed by an LLM. The decision is in [`dataset.yaml`](dataset.yaml). Credit the source:

> Source: OECD, PISA database (2012, 2015, 2018 and 2022 student questionnaire data files). Cite each dataset as the OECD asks.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

How to cite the dataset (from the publisher) and this repo.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
