# pdt-pisa

Metadata for the [Programme for International Student Assessment (PISA), student questionnaire](https://webfs.oecd.org/pisa2022/index.html), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** a slice (PublicDataToolkit Task 45): 103-104 variables in each of four cycles, 2012, 2015, 2018 and 2022, with data for four countries.

## What the dataset is

The OECD's Programme for International Student Assessment tests 15-year-old students in reading, mathematics and science every three years since 2000 (2022 was delayed a year), in up to 81 countries and economies. Students also answer a questionnaire about themselves, their families and their school. Each cycle is its own database.

This repo covers the student questionnaire file of four cycles:

| Release | Data file | Variables with records | Columns in the data file |
|---|---|---|---|
| `2012` | `INT_STU12_DEC03.txt` (fixed-width text, read by the SAS control file) | 23 | 103 |
| `2015` | `CY6_MS_CMB_STU_QQQ.sav` | 24 | 104 |
| `2018` | `CY07_MSU_STU_QQQ.sav` | 24 | 104 |
| `2022` | `CY08MSP_STU_QQQ.SAV` | 24 | 104 |

The data files' extra 80 columns are the replicate weights, which `dataset.yaml`'s `design` names.

The variables are the identifiers (country, school, student; in 2012 also the questionnaire form), the final student weight and its 80 replicate weights, sex, grade, the ESCS index, the sense-of-belonging items (ST87 in 2012, ST034 from 2015) and the BELONG index, and the plausible values in reading (10, or 5 in 2012).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum. The 2015-2022 files and the codebooks come from webfs.oecd.org:

```bash
make download ARGS=--accept-terms
```

The 2012 files and the 2022 questionnaire are on www.oecd.org, which refuses scripts; `sources.yaml` gives the steps to fetch them in a browser. The OECD's 2012-2018 questionnaires sit behind a bot check, so the question text for those cycles comes from the US versions published by NCES, and each record says so. `make data` then writes the common-format files, `data/processed/pisa-<release>-student.parquet`, with the rows of four countries (USA, GBR, DEU, JPN; `data_rows` in `dataset.yaml`), and checks that every cell round-trips.

## How to use the metadata

- `metadata/releases/<release>/student/variables.jsonl`: one record per variable, with its codes and missing types, and where each fact came from.
- `metadata/groups.jsonl`: per release, the plausible values (kind `plausible_values`) and the belonging battery.
- `dataset.yaml`'s `design`: the final weight and the 80 replicate weights (Fay's method). The replicate weights have no records of their own: the design names them, and they're plain columns in the data files.
- `metadata/links.jsonl`: each variable from 2015 to 2018 and from 2018 to 2022. ESCS is linked as `rescaled`, since the OECD publishes it rescaled for trend analysis; BELONG and the 2012 items aren't linked, and `build/report.md` says why.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

The data: cite each cycle's database as the OECD asks, in its terms' format: OECD (year), (dataset name), (data source) DOI or URL (accessed on (date)). The 2022 database, for instance, is at https://webfs.oecd.org/pisa2022/index.html.

This repo: pdt-pisa, PublicDataToolkit metadata for the PISA student questionnaire.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make data
make views
make check
```

The metadata tools (`make views`, `make check`) need only the toolkit's base install
(`pip install -e ../PublicDataToolkit`). Building or reading the data files (`make data`,
`scripts/extract.py`, and the data checks in `make check`) also needs pandas, numpy and
pyarrow: `pip install -e "../PublicDataToolkit[data]"`. Without them, `make check` skips
the data checks and says why.
